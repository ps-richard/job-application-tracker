# Job application tracker

A small full-stack application for tracking my job search.

## Objective

Build a small production-oriented application while learning the technologies used in modern web applications.

The project will evolve from a simple Node.js prototype into e Next.js application with TypeScript, Supabase/PostgreSQL, authentication and RLC (Row Level Security)

## Current Version 

The current version is a functional prototype built with:

- HTML 
- CSS 
- JavaScript
- Node.js
- JSON file persistence

## Architecture

Browser -> Node.js server -> data.json

## Current capabilities

- Create job applications
- View Applications
- Update Applications
- Delete Applications
- Persist data locally


## Learning goals

- Next.js
- TypeScript
- Server and Client Components
- API Routes
- PostgreSQL
- Supabase
- Authentication 
- Row Level Security
- Git/GitHub Workflow
- Pull Requests
- Vercel Deployment

## Project Evoluion
